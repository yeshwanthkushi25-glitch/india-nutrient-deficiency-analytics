# Team Upload Guide: How to Upload This Project to Your GitHub

Hello teammate! This package contains the entire **Nutrient Deficiency & Hidden Hunger Paradox Analytics** project.

Choose whichever method is easiest for you:

---

## ⚡ Method 1: The Easiest 1-Click Method (Double-Click `.bat`)

1. **Unzip** this zip file into a folder on your computer.
2. Go to [https://github.com/new](https://github.com/new):
   - Repository name: `india-nutrient-deficiency-analytics`
   - Select **Public**
   - Leave *"Add a README"*, *".gitignore"*, and *"license"* **UNCHECKED**
   - Click **Create repository**
   - Copy your repository URL (e.g., `https://github.com/YOUR_USERNAME/india-nutrient-deficiency-analytics.git`)
3. Double-click the file named:
   👉 **`UPLOAD_TO_MY_GITHUB.bat`**
4. Paste your repository URL and press **Enter**.
5. It will automatically initialize git, add all files, and push everything to your GitHub!

## 🚀 How to Make Your Website Live (GitHub Pages in 2 Clicks)

Once the project is in your GitHub repository:
1. Click **Settings** (top tab with gear icon).
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment**:
   - **Source:** *Deploy from a branch*
   - **Branch:** Select `main`
   - **Folder:** Select `/ (root)`
   - Click **Save**.
4. Wait 1 minute and refresh the page. Your website will be live at:
   `https://YOUR_USERNAME.github.io/india-nutrient-deficiency-analytics/`
